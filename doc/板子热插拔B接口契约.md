# B 阶段接入契约

这是 A 联调期间的接入设计，尚不是 B 实现或验收证据。先完成 A 的验收与提交，再开始本阶段编码。以技术方案、实施记录中的实验变体及用户提供的两份规则来源为约束。

## 文件所有权

1. 规则内核：`rules/{models,compiler,predicates,effects,interpreter}.py` 及新的内核单测。
2. 权威状态：`rules/adapter.py`、`game/{state,actions,manager,setup,phase,day_resolution}.py`、`knowledge/skill_status.py` 及新的权威集成测试。
3. 流程调度：`game/{night,day,action_turn}.py`、`moderator/{night_flow,day_flow,trigger_flow,play_runner,shell}.py`、脚本运行时接入及新的流程测试。

每个实现代理先确认共享契约，再修改自己的文件；不得自行扩大范围或创建嵌套代理。扩展默认值为空，保持 A 包的规范化语义摘要与旧快照兼容。

## 规则输入与效果

- 沿用 `EffectSpec → EffectIntent → ResolvedEffect`，不另建一套自由状态 patch。新操作固定在有类型词汇中，写入仍须由冻结表达式计算目标授权，并保留来源技能、请求、实例与触发 occurrence。
- 技能可绑定夜窗 ID，以及普通白天发言前后两个 hook。夜窗顺序与依赖复用冻结板子的窗口定义；缺失引用、重复引用和环路在编译时拒绝。警长、PK 与遗言不触发普通白天 hook。
- 触发声明包含已确认事实类型、`AUTOMATIC` 或 `PLAYER_CHOICE` 模式及有类型条件。表达式可有限读取当前来源事实和关系集合；不允许任意对象路径、回调或递归。自动请求只由 manager 从持久队列合成；玩家选择请求也必须绑定具体 occurrence。
- 玩家字段修改分别声明 `role_id`、`faction_id`、`victory_group_id`、`chat_group_ids`，类型分别为字符串、字符串、可空字符串、字符串列表。不得把身份、阵营、胜利与聊天权限合并为同一字段。
- 资源增减指定已声明资源和有界整数；能力授予/撤销指定冻结包中的技能与稳定 grant，保留旧实例供账本引用，新授予的实例身份绑定来源。不得按动作编码误消费另一个授权。
- 关系新增/删除显式声明关系类型与两个端点；通用状态可按 GAME、SEAT、ABILITY 作用域持久化。状态与关系使用离散 hook/回合边界过期，不能依赖墙钟。
- 流程变化使用有条件的通用效果，例如恢复当前白天或在边界完成后入夜。同一个技能可能随结果选择不同流程，因此仅在技能上写一个无条件 `return_policy` 不足以表达骑士的两个结果。

## 权威状态与提交

- `GameState` 持久化有类型关系、触发队列与工作流游标。触发 occurrence 至少绑定稳定 ID、来源事实与批次、技能实例、actor、模式、排序、状态和已安装的请求/窗口。
- 游标保存窗口、结算组、已完成收集窗口与白天返回点。原发言队列及 serial turn 仍是发言进度的唯一来源；恢复点不得另建一份互相冲突的队列。
- 窗口的收集完成与最终关闭分离。收集完成后拒绝新请求；同结算组全部准备完成才原子结算并关闭各窗。
- 同组前窗的狼刀只能提供声明允许的临时事实和私密披露，不先提交确认死亡。后窗的保护和治疗仍与狼刀在最终同一观察/结算组交互。
- manager 提供完成收集、提交规则组及推进工作流三个权威边界。命令只携带持久请求/occurrence/窗口身份；候选批次必须按本地冻结包重算并比较，不把调用方效果当权威。
- 新死亡在提交边界进入队列；自动与等待玩家选择共用队列，按稳定顺序执行、去重并限制预算。等待选择可以恢复；失败不得留下半份资源、身份、关系或队列变化。
- 队列、遗言与警徽边界排空之前，不检查胜负或执行入夜返回策略。预算耗尽保留可审计错误，不丢弃余项后宣布胜利。
- adapter 只向内核提供权威快照；玩家与脚本运行时只收到获授权投影。延迟披露在声明 hook 前不可投递；不能从私有成员列表推导候选目标。

## 最低行为验收

- 两个同相位夜窗：前窗提案及私密告知，后窗保护最终挡刀；加载/请求完成顺序不影响结果。
- 普通发言前后技能按结果中断或恢复，返回同一发言游标；PK、警长与遗言无此入口。
- 同批多名死者产生自动和选择触发；连带死亡继续入队，等待选择的快照恢复后不重复扣费或触发。
- 关系和状态到指定边界过期；身份四类字段、资源与能力授撤原子提交，非法授权与重复提交有明确结果。
- 实验白狼王、魅惑关系、决斗与查验变体由数据表达。远端验收通过实际脚本运行时、Gateway 与 manager；最终两个新板子的完整配置在 C 冻结引擎后加入。
